# 慢一点写

写作不是把想好的东西抄下来，而是**边写边想**。好的工具应该退到后面，让你只看见文字本身。

> 先写出来，再写好。
> > 删掉比想出来容易得多。

## 三种写法的对比

| 方式 | 适合 | 每天字数 |
|:---|:---|---:|
| 晨间书写 | 整理思路 | 750 |
| 番茄钟 | 长文初稿 | 2000 |
| 自由写作 | 找到题目 | 不限 |

## 草稿里的小工具

- 打字时按 <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>F</kbd> 进入专注模式
- 想查资料，先记一个 `TODO`，写完再回头
  - 不要中途切出去
  - 也不要回头改错别字

```js
// 一天的进度
const goal = 1000
const progress = (words) => Math.min(words / goal, 1)
```

写到这里，今天的任务就完成了一半。剩下的，明天再说。
