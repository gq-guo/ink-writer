# Ink

> 极简、本地优先的 macOS Markdown 写作软件。

Ink 只做一件事：让你安静地写字。没有账号、没有云端、没有花哨的工具栏。
文档就是你磁盘上的普通 `.md` 文件，用任何编辑器都能打开，换软件也不会被锁住。

---

## 特点

### 专注写作

- **像一本正在编辑的书**：正文用衬线字体排版，暖纸色界面、没有花哨的颜色和圆角
- **安静的 Markdown**：光标不在的行隐藏 `#`、`**`、反引号等标记，光标所在行照常显示源码；
  也可以在设置里改为始终显示。文件内容永远是标准 Markdown，一字不改
- **Focus Mode**（⌘⇧F）：只突出当前段落，其余内容淡出
- **Typewriter Mode**（⌘⇧T）：打字时当前行始终停在屏幕中央
- **安静的界面**：工具栏平时隐藏，鼠标移到窗口顶部才浮现；连续打字时状态栏和目录也会淡出
- **排版可调**：写作字体、字号、行高、栏宽随手调整，内置 iA Writer Quattro 与 JetBrains Mono 字体

### 本地优先，安全可靠

- **普通文件**：文档保存在你选定的文件夹（默认 `~/Documents/Ink`），可以放进 iCloud Drive 或任何同步盘
- **自动保存**：停笔即保存，写入采用原子操作，断电或崩溃也不会留下写了一半的文件
- **外部修改提醒**：文件被其他程序改动时，可以选择保留自己的版本、加载磁盘版本或另存副本
- **兼容旧文件**：自动识别 GBK 编码，保存时统一转为 UTF-8；兼容 Windows 换行

### 整理与查找

- **侧边栏**：全部文档、最近、收藏，按今天 / 昨天 / 本周 / 更早分组
- **Quick Open**（⌘P）：按文件名模糊搜索，同时搜索正文内容
- **命令面板**（⌘K）：所有功能一处可达
- **悬浮目录**：正文右侧一列淡淡的短横线，悬停展开为目录，点击跳转
- **字数统计**：中文按字、英文按词分别统计，附段落数、句子数与阅读时长

### 原生 Mac 体验

- 完整的原生菜单栏、⌘, 设置面板、浅色 / 深色主题跟随系统
- 在 Finder 中双击 `.md` 文件、使用「打开方式」，或拖到 Dock 图标即可打开
- 输入时检查拼写（可在设置中关闭）
- 图片可直接拖入或粘贴，自动保存到文档旁的 `assets/` 文件夹
- 导出为单个 HTML 文件，或通过系统打印另存为 PDF
- 简体中文 / English 界面，默认跟随系统语言
- 支持超大文档：超过 10MB 自动进入性能模式，保持流畅
- 应用内自动更新

## 安装

支持 macOS 10.15 及以上，Apple Silicon 与 Intel 通用。

**一行命令安装（推荐）**

```bash
curl -fsSL https://raw.githubusercontent.com/gq-guo/ink-writer/main/scripts/install.sh | sh
```

脚本会从 [GitHub Releases](https://github.com/gq-guo/ink-writer/releases) 下载最新版本，校验 SHA-256 后安装到 `/Applications`。

**手动安装**

从 [Releases](https://github.com/gq-guo/ink-writer/releases/latest) 下载 `.dmg`，把 Ink 拖进「应用程序」。
当前版本尚未经过 Apple 公证，首次打开前需要在终端执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/Ink.app
```

## 快捷键

| 功能 | 快捷键 |
|---|---|
| 新建文档 | ⌘N |
| 打开文档 | ⌘O |
| 立即保存 | ⌘S |
| Quick Open | ⌘P |
| 命令面板 | ⌘K |
| 设置 | ⌘, |
| 显示 / 隐藏侧边栏 | ⌥\ |
| 查找 | ⌘F |
| Focus Mode | ⌘⇧F（Esc 退出） |
| Typewriter Mode | ⌘⇧T |
| 切换深浅色 | ⌘⇧D |
| 放大 / 缩小字号 | ⌘= / ⌘- |
| 导出 HTML | ⌘⇧E |

中文输入法组字期间，快捷键不会被误触发。

## 隐私

Ink 不收集任何数据：没有遥测、没有埋点、没有账号。
唯一的网络请求是启动后检查更新（读取 GitHub Releases 上的版本信息），不携带任何文档内容或个人信息。
你的文档只存在于你自己的电脑上。
